# Brand guides

One guide per tenant. Each is generated from `relay/lib/tenants.mjs`,
which is the same file the mailer reads, so a guide cannot describe a
brand the mailer does not use.

Regenerate with `node relay/scripts/write-brand-guides.mjs`.

- [MobileMonero - brand and email style guide](./mobilemonero.com.md) - `mobilemonero.com` - Monero mining on a phone, the fleet that runs it, and what we published.
- [31 Harbor - brand and email style guide](./31harbor.com.md) - `31harbor.com` - Agent identity, trust scores, contracts and the fleet that holds them.
- [Party Favor Photo - brand and email style guide](./partyfavorphoto.com.md) - `partyfavorphoto.com` - Bookings, the leads behind them, and the shoots on the calendar.
- [Jobby McJobberson - brand and email style guide](./jobbymcjobberson.com.md) - `jobbymcjobberson.com` - The applications, the resumes and the mailboxes that make them possible.
